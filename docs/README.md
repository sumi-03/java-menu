# 📌 점심 메뉴 추천

## ☑️ 구현할 기능 목록

### 🟤️ 입력값 안내 및 입력 관련
- 메뉴 추천을 받을 코치 이름 입력 안내를 출력하고 이름을 입력받는다.
- 각 코치가 먹지 못하는 메뉴 입력 안내를 출력하고 메뉴를 입력받는다.

### 🟤 입력값 검증 관련
- 코치들의 이름이 ,(콤마)로 잘 구분되어있는지 확인한다.
- 코치들의 이름이 2글자 이상 4글자 이하인지 확인한다.
- 입력한 코치들이 2명 이상 5명 이하인지 확인한다.
- 각 코치가 먹지 못하는 메뉴가 ,(콤마)로 잘 구분되어있는지 확인한다.
- 각 코치가 먹지 못하는 메뉴가 0개 이상 2개 이하인지 확인한다.

### 🟤 메뉴 추천 관련
- 먼저 Randoms.pickNumberInRange()의 결과에 따라 각 요일별 추천할 카테고리를 정한다. (1이면 일식, 2면 한식, 3이면 중식, 4면 아시안, 5면 양식)
  - 추천할 수 없는 카테고리인 경우 다시 Randoms.pickNumberInRange()를 통해 임의의 값을 생성해서 추천할 카테고리를 정한다.
- 이후 정해진 카테고리에 있는 메뉴를 Randoms.shuffle()을 통해 임의의 순서로 섞고 첫 번째 값을 코치가 먹을 메뉴로 추천한다.
  - 추천할 수 없는 메뉴인 경우 다시 섞은 후 첫 번째 값을 사용한다.

### 🟤 출력 관련
- 메뉴 추천 결과를 출력한다.
- 추천 완료 안내 문구를 출력한다.

### 🟤 예외 처리 관련
- 올바르지 않은 입력을 할 경우 `IllegalArgumentException`을 발생시키고, `[ERROR]`로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
